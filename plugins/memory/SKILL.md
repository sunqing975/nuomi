# memory 技能

## 什么时候写（memory_write）
- 用户主动分享值得长期记住的信息：名字、偏好（食物/颜色/习惯）、重要事件、约定
- 只保存真正重要的，不要每轮都存；一句话存一条
- 语气细节（"我今天累"）默认不存，除非是持续偏好

## 什么时候读（memory_read）
- 回答涉及用户个人情况、且回答质量依赖这些背景时
- 先看注入的记忆事实（系统提示里已有），不足再调用 memory_read

## 规则
- 记忆是对用户的尊重，不是数据采集：写之前判断"下个月还用得上吗"
- 引擎已注入最近记忆，不要在每轮都读
